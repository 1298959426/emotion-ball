🧠 软件系统架构（小白照抄即可）
  • 1. 方向识别层（DoA）：ReSpeaker 自带 ODAS / VAD + GCC-PHAT，直接输出 0~360° 角度；Pi 端一个 Python 脚本订阅角度，角度变化超过 20° 且能量超过阈值就推送一次事件。
  • 2. 语音理解层（ASR + Emotion）：
    本地零成本 Vosk 中文小模型 + 关键词匹配（"你好"/"谢谢"/"讨厌" → 映射 happy/love/angry） 云端省心 讯飞语音听写（免费额度够家用）+ 简单情感分类
  • 3. 显示渲染层（就是你看到的这张 HTML）：
    • Pi 上 Chromium 以 --kiosk --start-fullscreen 自启动打开本地 emotion-ball-preview.html。
    • Python 后端通过 WebSocket 把 {deg, emotion} 推给网页，网页更新 --tx/--ty 让球偏移、切换表情类名。
    • 屏幕分辨率设置为圆形屏原生分辨率（例如 1080×1080），body 用 width:100vw;height:100vh 刚好铺满。
  • 4. 方向→偏移换算：屏幕半径 R = 屏幕短边的 22%；偏移量 = (R·sin(θ), -R·cos(θ))，其中 θ 为 0° 指向"正前方/屏幕上方"。Demo 里按此实现，可直接复用。
